`@ex-grid/mantine` is ExGrid for React's Mantine Wrapper: `MantineExGrid` stands the grid in Mantine's Paper, draws every Chrome slot in Mantine's components at the size the Density maps onto, and maps the Visual Tokens onto the Mantine theme in light and dark. The cells are drawn in Mantine's default font stack with widths measured for every face it resolves to, so `####` is judged by the face on screen; `mantineChrome` is the Wrapper's slots alone. It is published with 0.3.0.
