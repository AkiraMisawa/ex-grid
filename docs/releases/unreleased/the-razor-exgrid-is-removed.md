Product: ExGrid
Kind: Breaking
ADR: 0370

The Razor component drawn in .NET, `ExGrid.Components.ExGrid<TRow>`, is removed with `ExGridRow<TRow>` and the logic only it ran: `ExGrid.Script.ExGrid<TRow>` takes the same `Source` or `Rows`, `Columns` and callbacks, so a page changes `@using ExGrid.Components` to `@using ExGrid.Script` (`ExGridStylesheet` stays where it was). A server's rows come through `GridSource.Fetch`: the grid takes no `Window`, `WindowStart` or `OnRangeNeeded`. `IGridChrome` keeps `ScriptSlots`, `Stylesheets` and the view overloads (`Menu(GridMenuView)`, `FilterPanel(GridFilterView)`, `LoadingIndicator(GridLoadingView)` and the rest); the context overloads and their records (`FilterPanelContext`, `FindContext`, `CellEditorContext`, `ColumnMenuContext`, `NameBoxContext`, `FormulaBarTextContext`, `EditorCompletionContext`, `LoadingContext`, `CellMessageContext`, `SelectionSummaryContext`) are removed, since a Chrome now fills only the Script Core's slots, its controls marked with `ScriptSlotAttributes`. The Script Core draws the Selection Summary and a cell's message itself. `ContextMenuContext<TRow>` loses the Razor menu's members and is `(Row, Column, Type, Selection, RowSequenceVersion, Close)`. `GridPointedAt<TRow>` holds only `InBrowser`, and `GridPointedInBrowser<TRow>` takes no `taken` callback. The C# key tables and rules the Razor component decided by (`MenuKeys`, `MenuKeyResolver`, `ClipboardParse`, `ClipboardPayload`, `OperandReading`, `FilterPanelChoices`, `ChangeHighlightRules`, `EditorReference`, `EditorRewrite`, `PointState`, `GridPointArrow`, `GridPointDashes<TRow>`, `GridPointedPress<TRow>`, `GridPointedStep<TRow>`, `HeldSelection`, `HeldSummaryFigures`, `FindOutcome`, `GridActionRefusal<TRow>` and `GridCommitRefusal`) are removed: the Script Core decides each in the browser, and a refusal reaches `OnRefused` as before. In ExGrid.MudBlazor, the parts drawn for the Razor component (`MudExGridMenu`, `MudExGridFilterPanel`, `MudExGridFindPanel`, `MudCellEditor`, `MudEditorCompletion`, `MudNameBox` and `MudFormulaBarText`) are removed; `MudGridChrome` draws the same surfaces over the Script Core.
