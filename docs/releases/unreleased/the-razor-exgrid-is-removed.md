Product: ExGrid
Kind: Breaking
ADR: 0370

`ExGrid.Components.ExGrid<TRow>` is drawn by the Script Core in the browser in place of .NET: the name, the `Source` or `Rows`, the `Columns` and the callbacks stay, so a page keeps `@using ExGrid.Components`, and `ExGridRow<TRow>` and the logic only the grid drawn in .NET ran are removed. A server's rows come through `GridSource.Fetch`: the grid takes no `Window`, `WindowStart` or `OnRangeNeeded`. `IGridChrome` keeps `ScriptSlots`, `Stylesheets` and the view overloads (`ColumnMenu(GridMenuView)`, `ContextMenu(GridMenuView)`, `FilterPanel(GridFilterView)`, `LoadingIndicator(GridLoadingView)` and the rest); the context overloads and their records (`FilterPanelContext`, `FindContext`, `CellEditorContext`, `ColumnMenuContext`, `NameBoxContext`, `FormulaBarTextContext`, `EditorCompletionContext`, `LoadingContext`, `CellMessageContext`, `SelectionSummaryContext`) are removed, since a Chrome now fills only the Script Core's slots, its controls marked with `ScriptSlotAttributes`. The Script Core draws the Selection Summary and a cell's message itself. `ContextMenuContext<TRow>` loses the members of the menu drawn in .NET and is `(Row, Column, Type, Selection, RowSequenceVersion, Close)`. `GridPointedAt<TRow>` holds only `InBrowser`, and `GridPointedInBrowser<TRow>` takes no `taken` callback. The C# key tables and rules the grid drawn in .NET decided by (`MenuKeys`, `MenuKeyResolver`, `ClipboardParse`, `ClipboardPayload`, `OperandReading`, `FilterPanelChoices`, `ChangeHighlightRules`, `EditorReference`, `EditorRewrite`, `PointState`, `GridPointArrow`, `GridPointDashes<TRow>`, `GridPointedPress<TRow>`, `GridPointedStep<TRow>`, `HeldSelection`, `HeldSummaryFigures`, `FindOutcome`, `GridActionRefusal<TRow>` and `GridCommitRefusal`) are removed: the Script Core decides each in the browser, and a refusal reaches `OnRefused` as before. In ExGrid.MudBlazor, the parts drawn for the grid drawn in .NET (`MudExGridMenu`, `MudExGridFilterPanel`, `MudExGridFindPanel`, `MudCellEditor`, `MudEditorCompletion`, `MudNameBox` and `MudFormulaBarText`) are removed; `MudGridChrome` draws the same surfaces over the Script Core.
