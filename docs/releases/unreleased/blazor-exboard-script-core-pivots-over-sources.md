`ExBoard.Script.ExBoard` draws a pivot over a source held in .NET: the browser's pivot reads the `PivotSource` the source's `Pivot` makes over each narrowing through .NET, as `ExPivot.Script.ExPivot` reads one, building its report and totals from the Leaf Aggregates it answers, and a link from that pivot asks the source's `Under` for the values under the selected cells. `BoardSource.Pivot` takes the place of `BoardSource.Report` in both ExBoard components, so one source serves both: the Razor component builds its report over the `PivotSource` itself.
