Product: ExGrid
Kind: Behaviour
ADR: 0050, 0100

Where you declare the Alt key alone (`Alt+Alt`), the keys typed after its release wait until your handler for the release has run, a round trip on a Blazor Server circuit: if it handed the keyboard to a frame of your own (`HandKeyboardToFrameAsync`), they go to that frame in order; if not, they are the grid's, as before. Typing straight after Alt is therefore never answered before you have heard the Alt.
