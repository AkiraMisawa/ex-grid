Product: ExPivot
Kind: Added
ADR: 0152

`@ex-grid/pivot-engine` adds `LocalPivotReportSource`, the report source over a Pivot Source as `PivotReportSource.From` is in C# (ADR-0151 to ADR-0153): Windows of a report with the whole report's metadata, the cells a Change Batch moved marked with its Report Version, label widths under the label geometry the settings give, and Copy, the Selection Summary, a field's Items and Show Details under a Report Version, computed in slices. It answers every Window whole, with no Window Changes, and `PivotChangeTimes` stamps a change's highlight on the Consumer's clock. It is published with 0.3.0.
