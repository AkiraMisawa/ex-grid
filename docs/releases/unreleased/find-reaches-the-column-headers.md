Product: ExGrid
Kind: Behaviour
ADR: 0333

Find now searches the visible column headers and Header Group labels as well as the rows, the header rows coming before the first data row: a step that wraps past the last row, or finds no row, stops on the first header that matches (the last, backward), and the next step goes on from it. A header found is the current match: it wears `ex-match-mark-current`, is scrolled into view across, and the panel names it, "Found in the header Trader" (`FindOutcome.FoundInHeader`, `FindPanelLabelIds.FoundInHeader`, the header's text in the new `FindContext.FoundHeader`), while the header carries `aria-current="true"`; the Focus does not move. Every header on screen that matches wears `ex-match-mark`, judged by `GridFind.Matches` over its text whoever answers Find. A search for text that is also a column's header therefore stops on that header once per round. The Consumer's `GridFindRequest` and answer are unchanged. A selection of more than one cell searches no header, hidden columns' headers are not searched, Replace never writes a header, and the new `FindsHeaders` parameter (default `true`) turns it off, as ExSheet does for its column letters.
