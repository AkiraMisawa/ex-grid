Product: ExChart
Kind: Added
ADR: 0370

`ExChart.Script.ExChart` and `ExChart.Script.ExSurface` are Blazor's ExChart and ExSurface drawn by their TypeScript Script Core, the first step of moving Blazor's ExChart onto it (ADR-0370 section 1): the drawing, the tooltip, the legend, Chart Filters, View as table and the turning of a surface run in the browser on both hosting models, while the `ChartDefinition` and `SurfaceDefinition` are built in .NET. They carry every parameter and event of the Razor components but `Spec`, `Sources` and `Chrome`, and `DownloadAsync` and `SvgTextAsync`. A `Format` crosses as the text it writes each value the definition holds; an axis `Format`, a `ChartSeries.Sampled` series, a `Format` on candles, a `Format` on a surface axis placed by value or on a mesh that does not write plainly, a `ZFormat` on a mesh, and two Row Keys or two surface axis values that reach the browser as one value are refused by name with a `NotSupportedException`. A candle's values, and every value in its CSV, are written as numbers (`3.3`, not a decimal's `3.30`). Building ExChart from source now needs Node, as ExGrid's and ExPivot's builds do, which bundles the script it ships.
