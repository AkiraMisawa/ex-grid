`@ex-grid/pivot-engine` lays a Sibling Window out: its cube checks that the window, its margins and its rest cells compose to the parent and that each margin sorts strictly beyond its edge, and the report gives every sibling outside the window a Pending Row (`PivotRowRole` `pending`), so the row count is the whole set's; `valueAt`, `rowPath` and `detailsQuery` refuse a Pending Row by name. Pending Rows are made a few hundred at a time in `pivotReportAsync`'s and the report source's slices (PV-40), so a window over a million siblings leaves the page painting. `LocalPivotReportSource` asks a server that answers Level Aggregates for windows only once it refuses the question whole past the cap, asks again with the windows moved when a report Window reaches Pending Rows, keeping the rows' sequence, and refuses a Copy or a Selection Summary that reaches one with `rowsNotAnswered`. `levelQueryForLayout` takes the window as a third argument and carries the order of each field sorted by a value shown as computed.
