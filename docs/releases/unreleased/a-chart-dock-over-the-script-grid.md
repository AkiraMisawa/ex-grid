`GridChartBridge` charts the selections of `ExGrid.Script.ExGrid` through `ScriptGrid`, set in place of `Grid`, and `MudChartDock` draws its charts with the Script Core when `ScriptCore` is set. The grid's Context Menu offers "Chart" and "Add to chart" over the Script Core, and a menu opened at once after a command offers what that command left.
