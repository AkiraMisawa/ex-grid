A report a server computes: `ReportSource` takes a `PivotReportSource`, whose server runs the same engine (`PivotReportSource.From`) and sends only the Windows the grid shows, then Window Changes checked by a Window Digest. `PivotReportSource.Fetch` carries your transports, `PivotReportJson` writes their questions and answers, and a remote report recovers a missing Baseline Window by itself (#70).
