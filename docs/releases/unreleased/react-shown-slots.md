Product: ExGrid
Kind: Added
ADR: 0350, 0390

ExGrid for React's `chrome` prop takes `cellMessage`, `selectionSummary` and `loadingIndicator`: a cell's message, the Selection Summary's figures and a loading indicator can be drawn by a design system of your own, while when each shows and what it says stay the grid's. The Script Core takes the same slots as mount functions. It is published with 0.3.0.
