Under React, the Sheet lists the matching function names, Linked Tables, a table's columns and an argument's fixed values as a Formula is typed, with the argument hint beneath them, in the cell and in the Formula Bar: ↑ and ↓ choose, Tab writes the choice, and Escape closes the list. ExGrid in TypeScript paints the same list and hint for any grid given `completeEditorText`, answered now or with a promise, and exports `EditorCompletion` and `EditorHint` to answer with.
