New package `@ex-grid/pivot-mantine`: `MantinePivot` draws ExPivot for React in Mantine's Paper, its Field List, Pivot Toolbar, menus, panels, report filters, Stale Report notice and Show Details' tabs and dialog in Mantine's components (`mantinePivotChrome`) and its report grid's Chrome in `@ex-grid/mantine`'s. Its stylesheet maps the pivot's Visual Tokens onto the Mantine theme, so a change of scheme recolours it with no render. It is published with 0.3.0.
