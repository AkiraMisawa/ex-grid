In the TypeScript core, a key typed on the grid while a menu slot's contents have not yet taken the keyboard is the menu's, answered against the place the core keeps, and the contents' focus request names the item that place stands on in the new `GridMenuSlotContext.focusItem`. `wireMenuItems`, `answerMenuKey` and `takeMenuFocus` wire a menu's items on markup another framework drew, as React's `useMenuItems` now does, and `GridHandle.holdSettled` holds the Settled Mark while a Framework Adapter's contents are owed.
