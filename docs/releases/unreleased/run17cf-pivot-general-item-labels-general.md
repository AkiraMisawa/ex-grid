ADR: 0060

A number Item whose field has no `format` is labelled in Excel's General, the rule a value with no number format is shown by: at most eleven characters besides a minus sign, where up to 15 significant digits were shown, so `1.23456789012345` reads `1.23456789` and `123456789012.345` reads `1.23457E+11`, in the report and in Filter…'s list alike. A copy of the label still carries the number in full in the HTML that Excel reads (`123456789012.345`), and the label as shown in the text flavour, as a value cell's copy does. A negative Item takes `-` in every culture, where sv-SE, fi-FI and nb-NO wrote `−` (U+2212). An Item is labelled from its number as a `double`, as it is keyed, where a value of a Decimal column is shown from its exact `decimal`: for a decimal of more than fifteen significant digits whose fifteen digits fall exactly halfway between the two forms that fit, the label and a value of the same number can choose differently (`1E-01` and `0.100000001` for `0.1000000004999999`). The Item itself, and a Hidden Item's key, are unchanged; a Consumer that wants more digits gives the field a `format`.
