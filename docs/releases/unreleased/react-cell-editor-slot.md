ExGrid for React's `chrome` prop takes `cellEditor`: the Cell Editor's field can be drawn by a design system of your own, from `useCellEditor(context)`, while the box over the cell, the keys and the uncommitted text stay the grid's. The Script Core takes the same slot as a mount function. It is published with 0.3.0.
