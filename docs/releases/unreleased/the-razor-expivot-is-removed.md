Product: ExPivot
Kind: Breaking
ADR: 0370

`ExPivot.Components.ExPivot` is drawn by the Script Core in the browser in place of .NET: the name, the `PivotSource` and the `PivotLayout` stay, and its `Chrome` takes the Pivot Chrome that `PivotChrome` took. Its `ReportSource`, the report Windows a server computed (ADR-0151), goes with it: a server answers Leaf Aggregates through `PivotSource.Fetch`, and the report is built in the browser. `IPivotChrome` keeps `GridChrome`, `Stylesheets`, `ScriptSlots` and the view overloads; the context overloads (`Toolbar(PivotToolbarContext)` and the rest) and their records are removed, since a Chrome now fills only the Script Core's slots, from a view of data, its controls marked with `PivotScriptSlotAttributes`. In ExPivot.MudBlazor, the parts drawn for the pivot drawn in .NET (`MudPivotToolbar`, `MudPivotFieldList`, `MudPivotMenu` and the rest, with `MudPivotButton` and `MudPivotIconButton`) are removed; `MudPivotChrome` draws the same surfaces over the Script Core.
