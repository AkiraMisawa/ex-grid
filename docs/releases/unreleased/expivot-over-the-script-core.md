Product: ExPivot
Kind: Behaviour
ADR: 0370

`ExPivot.Components.ExPivot` is drawn by its TypeScript Script Core (ADR-0370 section 1): the report, the PivotTable Fields pane and the Pivot Toolbar run in the browser on both hosting models, while the `PivotSource` answers in .NET. Each question the report asks crosses to the source as PivotJson, the source answers with its Leaf Aggregates, and the report and its totals are built in the browser from them; a source's `Changed` is heard and the report asks again, once for a Refresh under way. `Label` is asked for every id the pivot and its grid have words for each time the parameters are set. A field's `OrderKey` is called in .NET for each Item an answer names, and the keys cross with the Items, in their .NET type's order, as a text, a number, a Boolean or a whole number (integers, decimals, dates and times, a `Guid`, an enum): text keys are now compared ordinally where they were compared in the current culture, and a key of another type, two types in one field and a function that throws are refused by name, field and Item included, when the report orders by them (ADR-0412). A call larger than a hub's 32 KB message crosses as a gzip stream. Building ExPivot from source now needs Node, as ExGrid's build does, which bundles the script it ships.
