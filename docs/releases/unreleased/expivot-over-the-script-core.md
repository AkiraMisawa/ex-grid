Product: ExPivot
Kind: Added
ADR: 0370

`ExPivot.Script.ExPivot` is Blazor's ExPivot drawn by its TypeScript Script Core, the first step of moving Blazor's ExPivot onto it (ADR-0370 section 1): the report, the PivotTable Fields pane and the Pivot Toolbar run in the browser on both hosting models, while the `PivotSource` answers in .NET. Each question the report asks crosses to the source as PivotJson, the source answers with its Leaf Aggregates, and the report and its totals are built in the browser from them; a source's `Changed` is heard and the report asks again. It carries `Layout` and `LayoutChanged`, `ShowFieldList` and `ShowFieldListChanged`, the sizes, `Density`, `Culture`, `Caps`, `RedrawInterval`, `ChangeHighlightDuration`, `DetailsView`, `OnShowDetails` and `Label`, which is asked for every id the pivot and its grid have words for each time the parameters are set, its words crossing only when they changed; the Chromes, `SelectionChanged`, the Selection Summary's parameters, `OrderKeyPolicies`, `Clock`, `Slicing`, `CellMetrics` and `ReportSource` are not carried yet, and `ExPivot.Components.ExPivot` still does all of them. A field with an `OrderKey` is refused by name. Building ExPivot from source now needs Node, as ExGrid's build does, which bundles the script it ships.
