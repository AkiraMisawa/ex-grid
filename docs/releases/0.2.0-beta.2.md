# 0.2.0-beta.2

Published: pending
Packages: ExGrid, ExGrid.MudBlazor, ExSheet.Engine, ExSheet, ExSheet.MudBlazor, ExSheet.Xlsx, ExGrid.Data, ExGrid.Data.Arrow, ExGrid.Data.Xlsx, ExPivot.Engine, ExPivot, ExPivot.MudBlazor, ExChart.Engine, ExChart, ExChart.MudBlazor, ExBoard
Target: net10.0

## Highlights

- The npm packages under `@ex-grid` are published for the first time, at this version. 0.2.0-beta.1 reached nuget.org, but its npm publish failed before it wrote any package; its notes, [0.2.0-beta.1](release-notes#0-2-0-beta-1), say what this version holds, and React starts at [React](getting-started/react).

## Breaking changes

None.

## Behaviour changes

None.

## ExGrid

- **Fixed:** On Blazor Server, a grid whose source changed just before its page was left no longer logs "Unhandled exception in circuit: A task was canceled." The state that change sent was called off by the closing circuit, and nothing was wrong (ADR-0370).

## ExSheet

- **Fixed:** While a cell is being edited on a Sheet whose toolbar is shown, Alt released alone and F10 still start no KeyTips, and now no longer open the browser's own menu either. In Chrome on Windows that menu took the keyboard from the edit, so the keys typed next went to the menu instead of the cell (ADR-0450).

## ExPivot

- **Fixed:** On Blazor Server, a pivot whose source changed just before its page was left no longer logs the cancelled notice of that change as an unhandled exception in the circuit (ADR-0370).

## ExChart

No change. Its packages are republished at this version.

No change. Its packages are republished at this version.
