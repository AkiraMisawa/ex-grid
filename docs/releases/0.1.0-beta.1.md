# 0.1.0-beta.1

Published: 2026-09-25
Packages: ExGrid, ExGrid.MudBlazor
Target: net8.0

## Highlights

- The first prerelease of ExGrid, an Excel-like grid for Blazor, virtualised on both axes: a million rows and a hundred columns paint the same few elements ([ExGrid](exgrid)).
- A spreadsheet user's rectangular selection, keyboard, and Enter and Tab cycling inside the selection ([Selection and keyboard](exgrid/selection)).
- Copy refused rather than truncated, and paste refused rather than spilled outside the selection ([Why a copy refuses rather than truncates](exgrid/clipboard#why-a-copy-refuses-rather-than-truncates)).
- `GridSource.From`, the reference for what sorting and filtering mean ([What sorting and filtering mean](exgrid/sorting-filtering#what-sorting-and-filtering-mean)).
- `ExGrid.MudBlazor`, which draws the grid's menus, filter panel and Cell Editor with MudBlazor's controls ([Built-in Chrome or MudBlazor's](exgrid/appearance#built-in-chrome-or-mudblazor-s)).

## ExGrid

- **Added:** The grid, `<ExGrid>`, which paints the rows and the columns on screen, whatever the size of the result, and raises a Range Request for the rest: it never fetches (ADR-0001, ADR-0004, ADR-0013).
- **Added:** `GridSource.From`, the in-memory source: case-insensitive, a Blank last in both directions, a stable sort, and a refusal by name rather than a guess (ADR-0023).
- **Added:** Pinned columns, Header Groups, Auto widths that only grow, and `####` for a number or a date that does not fit its column (ADR-0016, ADR-0032).
- **Added:** Rectangular selection with a Focus, Enter and Tab cycling inside it, and a selection dropped when the order of the rows changes (ADR-0011, ADR-0012).
- **Added:** Copy, refused past 1,000,000 cells rather than cut short, and paste by Excel's shape rules, refused rather than written outside the selection (ADR-0005, ADR-0014).
- **Added:** The Cell Editor with the Consumer's validation, edits as an Overlay the Consumer owns, and paste and fill that respect a column's Editable declaration (ADR-0007, ADR-0034, ADR-0035).
- **Added:** The filter panel, the column menu and the Context Menu, seams a design system can fill (`IGridChrome`), each taking the keyboard when it opens (ADR-0009, ADR-0010, ADR-0036, ADR-0039).
- **Added:** Action and Template columns, Row Kinds, Cell States and Row Stripes (ADR-0006, ADR-0020, ADR-0024, ADR-0038).
- **Added:** Appearance through Visual Tokens and a short list of classes, and geometry through C# parameters (ADR-0027, ADR-0028, ADR-0029).
- **Added:** `ExGrid.MudBlazor`: a paper, a Chrome and a stylesheet that put the grid in a MudBlazor application, at exactly the core's version (ADR-0030, ADR-0042).

It was verified under WebAssembly. Blazor Server was part of the design, and had not been exercised yet.

Its GitHub release carries no packages and no prerelease note: the release workflow refused to make a second release over the one GitHub's release page had made with the tag (ADR-0042). Install it from nuget.org.
