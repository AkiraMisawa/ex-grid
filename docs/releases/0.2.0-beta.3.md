# 0.2.0-beta.3

Published: 2026-11-03
Packages: ExGrid, ExGrid.MudBlazor, ExSheet.Engine, ExSheet, ExSheet.MudBlazor, ExSheet.Xlsx, ExGrid.Data, ExGrid.Data.Arrow, ExGrid.Data.Xlsx, ExPivot.Engine, ExPivot, ExPivot.MudBlazor, ExChart.Engine, ExChart, ExChart.MudBlazor, ExBoard
Target: net10.0

## Highlights

- The npm packages under `@ex-grid` are published for the first time, at this version. 0.2.0-beta.1 reached nuget.org, but its npm publish failed before it wrote any package; its notes, [0.2.0-beta.1](release-notes#0-2-0-beta-1), say what this version holds, and React starts at [React](getting-started/react). The tag `v0.2.0-beta.2` published nothing: its release stopped at the browser tests, whose drags this version drives as the browser does (ADR-0451).
- A Find step taken while the one before it is still being answered now waits for it, so Find next pressed twice always reaches the second match ([Sorting, filtering and find](exgrid/sorting-filtering); ADR-0451).

## Breaking changes

None.

## Behaviour changes

- **ExGrid:** A Find or error step taken while the one before it is still being answered now waits for it, and what is typed or clicked meanwhile waits too: Find next pressed twice goes to the second match however slowly the Source answers, where the second press used to call off the first and start from the same Focus. Esc cancels a step still out, and moves nothing. ExSheet's and ExPivot's find panels, which are the grid's, behave the same (ADR-0451).

## ExGrid

- **Fixed:** On Blazor Server, a grid whose source changed just before its page was left no longer logs "Unhandled exception in circuit: A task was canceled." The state that change sent was called off by the closing circuit, and nothing was wrong (ADR-0370).
- **Fixed:** On Blazor Server, a page left while its ExGrid's parameters were being sent to the browser no longer logs an unhandled exception in the circuit. The call was only called off by the closing circuit; any other failure is still raised (ADR-0451).

## ExSheet

- **Fixed:** While a cell is being edited on a Sheet whose toolbar is shown, Alt released alone and F10 still start no KeyTips, and now no longer open the browser's own menu either. In Chrome on Windows that menu took the keyboard from the edit, so the keys typed next went to the menu instead of the cell (ADR-0450).
- **Fixed:** On Blazor Server, a page left while its ExSheet's parameters were being sent to the browser no longer logs an unhandled exception in the circuit. The call was only called off by the closing circuit; any other failure is still raised (ADR-0451).

## ExPivot

- **Fixed:** On Blazor Server, a pivot whose source changed just before its page was left no longer logs the cancelled notice of that change as an unhandled exception in the circuit (ADR-0370).
- **Fixed:** On Blazor Server, a page left while its ExPivot's parameters were being sent to the browser no longer logs an unhandled exception in the circuit. The call was only called off by the closing circuit; any other failure is still raised (ADR-0451).
