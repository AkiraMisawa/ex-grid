# 01: A test for each clause of a criterion that no test asserts

Status: ready-for-agent
Roadmap: internal

**Why:** 110 criteria (109 MUST and FN-20, a SHOULD) passed the 0.2.0 sign-off with a clause of their Pass that no
test in any layer asserts: the tests named for the row check the rest, and the clause holds in the code as it
reads. The user signed off with them as they stood on 2026-11-07, as 0.1.0's 37 were
([`signoff-0-1-0-gaps` 01](../../signoff-0-1-0-gaps/issues/01-tests-for-the-unasserted-clauses.md)), and each
becomes a test here. The record is [`verification/2026-11-09-linux-signoff/results.md`](../../../../verification/2026-11-09-linux-signoff/results.md), where each reads `pass, accepted as is`.

**What:** for each row below, a test for the clause the note names, in the lowest layer that can see it, carrying
the row's ID in its name (CLAUDE.md, "Tests"). A layer-3 test earns its run (ADR-0370 section 11): where the clause
is one layer 1 or 2 can judge, it goes there. A test that fails is a defect in the product, fixed as one, not a
criterion to restate. Each note is the record's, its line numbers 0326ce27's (v0.2.0-rc.4, which v0.2.0 ships);
where it names no missing clause, the record's evidence is the test to widen.
