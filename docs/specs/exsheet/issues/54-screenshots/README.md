# The Sheet Toolbar on /sheet (tickets 54 and 160)

Screenshots of `/sheet` on the WebAssembly host, under the built-in Chrome (`*-builtin.png`) and
ExSheet.MudBlazor's (`*-mud.png`), taken on 2026-10-02 with Chromium on Linux, for the pull
request. They show:

- `toolbar-*`: the default row and the page's own row.
- `palette-*`: the Fill's palette.
- `number-format-*`: the Number Format's list.
- `keytips-rows-*` and `keytips-home-*`: the KeyTips after Alt (or F10), and after H.
- `editing-*`: the toolbar greyed out while a cell is being edited.

They are pictures, not a record that anything passed: the layer-3 specs are that.
